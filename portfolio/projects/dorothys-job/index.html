Engineering Systems

Custom UI Focus Navigation

Navigating complex UI menus with a gamepad requires a robust focus system. I engineered a custom C++ UI navigation subsystem that supports both grid-based and linear layouts.

  • Input-Aware: Dynamically swaps control schemes between Keyboard, Mouse, and Gamepad.
  • Focus Memory: Remembers the last selected widget when swapping between deeply nested menus.
  • Responsive: UMG layouts mathematically scale to maintain aspect ratios across all monitor resolutions.
UFocusManager.cpp 
void UFocusManager::UpdateFocus(UWidget* NewWidget) {
    if (!NewWidget || NewWidget == CurrentFocusedWidget) 
        return;

    // Store previous focus for backtracking
    FocusHistory.Push(CurrentFocusedWidget);

    // Broadcast event to trigger UI animations
    OnFocusChanged.Broadcast(CurrentFocusedWidget, NewWidget);

    CurrentFocusedWidget = NewWidget;
    NewWidget->SetKeyboardFocus();
}

Audio Architecture & Consumables

With a background in music, I took ownership of the FMOD integration. I built an event-driven Audio Manager subsystem in C++ that decoupled sound logic from game actors, drastically improving performance.

On the gameplay side, I developed a highly modular consumable architecture. By utilizing data-driven design (DataAssets), game designers could create and balance new power-ups and weapons entirely in the editor without requiring additional code support.
